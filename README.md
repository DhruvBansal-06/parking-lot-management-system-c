# 🚗 Parking Lot Management System (C)

## 📌 Overview
This project is a simple Parking Lot Management System built using C programming.  
It helps manage vehicle entry, exit, and parking slot allocation.

## 🚀 Features
- Vehicle Entry System  
- Vehicle Exit Tracking  
- Parking Slot Management  
- Revenue Calculation  

## 🛠️ Tech Stack
- C Programming Language  

## 📂 Project Structure
- main.c → Main logic  
- login.c → Login system  
- freelot.c → Available slots logic  
- revenue.c → Revenue calculation  
- struct.h → Data structures  

## ▶️ How to Run
1. Compile the code:
   gcc main.c login.c freeslot.c revenue.c struct.h
2. Run:
   ./a.exe
